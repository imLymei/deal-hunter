# Deal Hunter 🍴

Deal Hunter is a online game whish list website that hunts for deals in your next games across many virtual stores using [CheapShark API](https://apidocs.cheapshark.com). Multiple users can create and manage their own accounts on a single public our private server while sharing their whish list with anyone they want without limitations.

## Requirements

Depending on your intentions with this project you will have different requirements to be able to use it.

### Developer

If you intend to run this service, make changes to the code and see their effects you will need:

- [Node 22 or greater](https://nodejs.org)
- [pnpm](https://pnpm.io)

### Publisher/Release

If you only intend to run a full build of Deal Hunter at it's best performance and do NOT intend to modify you will need:

- [Docker](https://www.docker.com)

## Usage

Following the requirements both development and production usage have different setups.

### Development

1. Install dependencies

```bash
pnpm install
```

2. Run development server

```bash
pnpm dev
```

3. Access server at http://localhost:3000
